# Compatible doubles and weekly distribution

Applies the explicit total-frequency preference to generated sessions, including strength. Uses bounded deterministic date-only distribution, daily session/minute capacity, existing sport compatibility and key-session rules. Unknown time estimates do not activate strength duration.

The generation integration tests are consolidated here because targets can require compatible doubles; configuration and migration were introduced by the preceding commit. Moving dates preserves recipe content through the original content date. No athlete data or real plans are included.
