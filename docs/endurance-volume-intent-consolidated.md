# Endurance Volume Intent

Volume Intent projects the existing bottom-up session duration policy. Explicit coherent_volume mode makes that intent authoritative for running, cycling and swimming before placement and workout construction; NULL remains legacy. No top-down minutes formula is invented and load shares are not minute shares.

Strength remains on legacy duration. Intent diagnostics, progression provenance and final reconciliation are separated from prescription identity. No real athlete snapshots or database writes are included in this consolidation.

Preview integration also consolidates frequency-constraint labels/errors consumed by explicit intents. Existing execution-panel test assertions now derive their expected date from the same synthetic current-month fixture instead of a hard-coded historical month; assertions are preserved and no calendar behavior changes. These pre-existing validation adjustments are required for reproducible frontend validation on the current date.
